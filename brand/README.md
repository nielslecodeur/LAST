# $LAST brand

- `last-logo-1024.png`, `last-logo-512.png`: token logo (paper palette, riso offset). Safe inside a circle crop.
- `make_logo.py`: regenerates them (Pillow + Anton font, OFL: https://github.com/google/fonts/tree/main/ofl/anton).

```bash
python brand/make_logo.py brand path/to/Anton-Regular.ttf
```
